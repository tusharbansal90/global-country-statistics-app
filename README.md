# 🌍 Global Country Statistics Explorer

A fully interactive **data analysis dashboard** built with **Streamlit** to explore, compare, and visualize global country-level statistics such as population, GDP per capita, literacy, demographics, rankings, and a world map.

🔗 **Live App:** [https://global-country-statistics-app-jubimmsxnilkgasuimzqe.streamlit.app](https://global-country-statistics-app-jubimmsxnilkgasuimzqe.streamlit.app)

---

## 🚀 Project Overview

This project allows users to:

* Explore key statistics for any country
* Compare two countries side-by-side
* Analyze demographic indicators
* View global rankings
* Visualize data on an interactive world map

The goal is to turn a raw dataset into a **clear, insight-driven dashboard** that mimics real-world data analysis workflows.

---

## 📊 Key Features

### 🔹 Country Overview

* Population
* GDP per Capita
* Literacy Rate

### 🔹 Demographics

* Population Density
* Birth Rate
* Death Rate
* Infant Mortality

### 🔹 Global Rankings

* GDP Rank
* Literacy Rank
* Infant Mortality Rank

### 🔹 Country Comparison

* Compare two countries side-by-side
* Economic & literacy comparison
* Demographic contrast

### 🔹 Data Visualization

* Top 10 Countries by GDP per Capita (Bar Chart)
* Global Choropleth Map (GDP per Capita)

---

## 🗺️ Global Map View

The dashboard includes a world map that allows users to:

* Select a metric (e.g., GDP per capita)
* Visually compare countries across continents
* Identify global economic patterns

---

## 🧠 Key Insights (Examples)

* High GDP per capita does **not always** correlate with high population
* Developing countries tend to have higher birth rates and infant mortality
* Literacy rate strongly correlates with economic ranking
* Small countries can outperform large economies on a per-capita basis

## ▶️ How to Run Locally

```bash

git clone https://github.com/tusharbansal90/global-country-statistics-app.git

# Navigate to project directory
cd global-country-statistics-app

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```
